# 🚲🏔️ Чеклист сборов: Германия + Австрия — велопоход и хайки

Личный чеклист сборов к ~2-недельной поездке: кемпинги, радиальные хайки в австрийских Альпах до 3000 м, велосипед (Trek Checkpoint SL7 AXS) + ремкомплект.

**Открыть:** https://apolitov.github.io/planner/

Интерактивный чеклист: галочки сохраняются в браузере (localStorage), фильтры **⛰️ горы / 🚲 вело**, прогресс-бар, версия для печати.

Всё в одном файле [`index.html`](index.html) — без зависимостей.
